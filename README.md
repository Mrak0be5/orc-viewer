# Orc Warrior — просмотр моделей

Просмотрщик моделей женского орка-воина (Tripo → Blender → Unity HDRP).
Сайт: GitHub Pages этого репозитория. Модели и рефы описаны в `models.json`.

Режимы: PBR, Albedo, не-PBR (Lambert), глина, matcap, сетка, нормали, normal map, roughness, metalness, UV-чекер, flat.

Отдельная страница тауренши Байн — только её детали и полная сборка: `baine/` (https://mrak0be5.github.io/orc-viewer/baine/). Сборка — запись с `assembly` в `baine/models.json`: детали грузятся отдельными GLB и ставятся в пространство тела.
